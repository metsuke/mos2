# help

## NOMBRE
help – muestra ayuda corta de comandos

## SINOPSIS
help
help <comando>

## DESCRIPCIÓN
Uso: help [comando] - Lista sistema, apps y usuario, o la ayuda de uno indicando el origen.

Uso: help [comando] - Lista sistema, apps y usuario, o la ayuda de uno indicando el origen.

## OPCIONES
Ninguna. El primer argumento se interpreta como nombre de comando.

## EJEMPLOS
help
help version
help update

## SEGURIDAD
Comando de sistema.

## VÉASE TAMBIÉN
man, version, test
