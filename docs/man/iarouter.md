# IAROUTER

## NOMBRE

iarouter - enrutado a modelos locales o con clave

## SINOPSIS

- iarouter | iarouter status

## DESCRIPCION

Apagado por defecto. No envia a un modelo hasta usar o preguntar. Detecta Jan y GPT4All. Las claves no se listan en status. El puente HTTP, si existe, no es P2P.
