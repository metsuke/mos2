# iarouter

## NOMBRE
iarouter – estado del enrutador de modelos

## SINOPSIS

iarouter status

## DESCRIPCIÓN
Muestra si las llamadas están permitidas. Por defecto enabled=false.
No envía texto a la red. complete() es API de moslib para la campaña 08.
