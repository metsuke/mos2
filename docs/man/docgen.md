# DOCGEN

## NOMBRE

docgen - genera documentos desde json y tuplas

## SINOPSIS

- list | generate | tupla list | tupla add | tupla set | tupla generate

## DESCRIPCION

La fuente es el json o la tupla. generate pinta md y html. ingest es excepcional. tupla generate recorre hijos, escribe VEASE TAMBIEN en mans (sin citarse a si mismo) y html en docs/docgen/html/.
