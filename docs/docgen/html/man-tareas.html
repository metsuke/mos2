NOMBRE

tareas – lista y gestiona tareas locales

SINOPSIS

  • tareas
  • tareas [list|add <comando>|hecha <id>|tick]
  • tareas tick
  • tareas add
  • tareas hecha
  • tareas list
  • tareas ls
  • tareas [list|add <comando>|hecha <id>|tick] -

DESCRIPCIÓN

Manuales y automáticas en .mos/data/tareas.json. tick reencola automáticas de clase sistema que estén hechas. Una tarea en bloqueada_a11y_sec no se ejecuta.

SEGURIDAD

Comando de sistema. stdlib + moslib.
