iarouter

NOMBRE

iarouter – enrutador de modelos (local y remoto)

SINOPSIS

  • iarouter
  • iarouter detectar
  • iarouter estado
  • iarouter usar jan|gpt4all|grok|openrouter
  • iarouter check [all|share|jan|gpt4all|grok|openrouter] [twitter] [detalle]
  • iarouter share
  • iarouter publicar
  • iarouter clave grok|openrouter [borrar]
  • iarouter modelos [prov]
  • iarouter modelo [prov] [id]
  • iarouter preguntar <texto>
  • iarouter puente on|off|estado

DESCRIPCIÓN

Muestra el proveedor activo, detecta cuáles están disponibles y, solo con preguntar, envía el texto al modelo y lo imprime.

usar escribe la política local (enabled=true y el proveedor). La IA no escribe esa política.

modelos lista los ids que publica el proveedor. modelo fija el id activo (puede llevar espacios; el proveedor solo si el primer token es jan, gpt4all, grok u openrouter).

clave guarda la clave en .mos/config/ envuelta con moslib.core.secreto. No imprime la clave. Si existe XAI_API_KEY u OPENROUTER_API_KEY en el entorno y aún no hay valor en .mos, se copia al almacén.

CHECK

check sin argumentos ejecuta todos los diagnósticos (LAN + cada proveedor). check grok valida DNS/TLS/clave/models de api.x.ai. check grok twitter centra el escenario del cliente Grok dentro de X (paths /i/api/1.1/*, 404/410, diferencias Windows/Mac) y lista acciones manuales que MOS2 no puede aplicar por código.

DETECCIÓN

  • jan: HTTP local (127.0.0.1:1337) y, si falta, /24 privada con cache
  • gpt4all: HTTP local (127.0.0.1:4891) y, si falta, /24 privada con cache
  • grok: clave en .mos o XAI_API_KEY (se ingiere)
  • openrouter: clave en .mos o OPENROUTER_API_KEY (se ingiere)

Sin clave o sin servidor, el proveedor aparece como no disponible. usar un proveedor no disponible se rechaza. Si falta la clave de grok u openrouter, usar pide la clave (sin eco).

SHARE

share no cambia el anfitrión. Comprueba si Jan y GPT4All escuchan en localhost y en la IPv4 privada, y escribe una guía por entorno (macos/native, windows, linux/native) si la LAN no alcanza el puerto.

PUBLICAR

publicar es autorización explícita. Intenta una regla mínima de firewall hacia la LAN (perfil privado / no Internet). En macOS no puede crear la regla del Firewall de aplicaciones: deja la guía. No se ejecuta dentro de share ni de usar.

PUENTE

puente no es la malla P2P. Abre un HTTP de este MetsuOS en el puerto 17337 (0.0.0.0) que reenvía /v1/models y /v1/chat/completions al Jan o GPT4All de esta máquina. Off hasta puente on. Off con puente off. Rechaza cuerpos que mencionen .mos. Otro MetsuOS de la LAN puede usar la URL que imprime puente status como jan_url.

SEGURIDAD

Off por defecto hasta usar. No incluye rutas .mos en el payload salvo allowlist del humano. Las claves no van a git. El JSON del almacén no lleva el texto en claro. Quien copie a la vez .ia_wrap e ia_keys.json puede recuperarlas. Solo stdlib y moslib.
