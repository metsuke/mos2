# docs/docgen

Almacén y motor de regeneración de documentos (campaña 2026-09-14-01).

| Nivel | Uso |
|-------|-----|
| areas.json | Áreas REQ |
| specs/ | JSON por spec |
| root/ | JSON de ficheros de la raíz |
| pages/ | JSON del resto de docs/ |
| man/ | JSON por página man |
| templates/ | Plantillas |
| backup/ | Copia inmediata anterior (no se versiona el contenido) |

Los markdown publicados siguen en su sitio (docs/specs, man, raíz). Esta carpeta es la fuente de regeneración.
